# Portafolio profesional | Andres Perez

Este repositorio contiene mi portafolio profesional como Frontend Developer
especializado en eCommerce, VTEX IO, React, TypeScript y JavaScript.

El sitio no es solo una landing personal: funciona como una pieza de
presentacion profesional donde resumo mi experiencia, proyectos reales,
tecnologias, testimonios y forma de trabajo dentro de equipos de desarrollo,
diseno, QA y operacion e-commerce.

## Que comunica el portafolio

- Especializacion en frontend para eCommerce y VTEX IO.
- Experiencia construyendo y manteniendo tiendas para marcas LATAM.
- Proyectos reales con foco en storefronts, PLP, PDP, checkout, landings,
  componentes personalizados y ajustes post go-live.
- Conocimiento practico en React, TypeScript, JavaScript, GraphQL, Master Data
  y automatizacion/personalizacion con plataformas como Connectif.
- Trabajo colaborativo con equipos de diseno, calidad, gestion y clientes.
- Testimonios profesionales que respaldan responsabilidad, comunicacion,
  proactividad, calidad de entregas y curiosidad tecnica.

## Secciones principales

- **Hero**: presentacion principal, enlaces a proyectos, GitHub, LinkedIn y CV.
- **Proyectos**: seleccion de trabajos e-commerce y proyectos frontend.
- **Operacion**: marcas y tiendas reales en las que he participado.
- **Experiencia**: timeline profesional con metricas, tecnologias, marcas y
  responsabilidades clave.
- **Testimonios**: recomendaciones profesionales resumidas por rol.
- **Stack**: tecnologias y herramientas explicadas por area de especializacion.
- **Contacto**: canales directos para nuevas oportunidades o colaboraciones.

## Tecnologias y decisiones tecnicas

- HTML5 semantico.
- CSS3 personalizado con variables, componentes y responsive design.
- JavaScript ligero para navegacion mobile y animaciones progresivas.
- Sin Bootstrap ni frameworks de UI.
- Sin proceso de build ni dependencias obligatorias.
- Imagenes optimizadas en formatos modernos.
- SEO basico con meta tags, Open Graph, JSON-LD, `robots.txt` y `sitemap.xml`.
- Despliegue estatico compatible con GitHub Pages.

El objetivo tecnico es mantener una base liviana, facil de leer y facil de
evolucionar, priorizando rendimiento, accesibilidad y consistencia visual.

## Ejecutar en local

No requiere instalacion de dependencias. Puedes abrir `index.html` directamente
en el navegador o levantar un servidor local:

```bash
python -m http.server 8000
```

Luego visita:

```text
http://localhost:8000
```

## Mantenimiento

- Mantener HTML semantico y accesible.
- Conservar estilos organizados por responsabilidad y componente.
- Evitar dependencias innecesarias.
- Validar responsive en mobile, tablet y desktop.
- Optimizar imagenes y recursos estaticos.
